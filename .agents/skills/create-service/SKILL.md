# Инструкция для навыка `create-service`

Этот навык автоматизирует создание базовой структуры для новых сервисов в приложении.

## Когда применять этот навык:
- Когда пользователь просит "создай новый сервис", "напиши сервис" или явно вызывает команду `create-service`.

## Шаги, которые должен выполнить ИИ:
1. Если имя сервиса не указано в запросе пользователя, спросить его (например, "Как назовем новый сервис?").
2. Создать файл `services/<service_name>.py` (для простых сервисов) или папку `services/<service_name>/` с файлами `__init__.py` и `service.py` (если логика предполагается сложной).
3. Написать базовый класс сервиса. Обязательные требования к коду:
   - Использовать асинхронные методы (согласно правилу "Async everywhere").
   - Добавить логгирование операций (через `import logging` или встроенный логгер проекта).
   - Если сервис работает с БД, использовать только асинхронный SQLAlchemy (`async SQLAlchemy`).
   - Использовать типизацию (type hints) в методах.
4. Вывести пользователю краткое сообщение об успешном создании и небольшой пример того, как импортировать и использовать этот сервис в хендлерах бота (FastAPI / aiogram).
