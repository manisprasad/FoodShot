# Инструкция для кастомной команды `example-command`

(Этот файл — шаблон "Навыка" (Skill). Навыки — это ваши собственные ИИ-команды. Имя папки и значение `name` сверху — это то, как навык будет называться.)

## Когда применять этот навык:
- Когда пользователь просит "создай новый сервис" или "запусти example-command".

## Шаги, которые должен выполнить ИИ:
1. Спросить пользователя, как должен называться новый сервис.
2. Создать папку с таким именем в директории `services/`.
3. Создать внутри базовый файл `__init__.py` и `service.py`.
4. Написать базовый класс сервиса с логгированием.
5. Сообщить пользователю об успешном создании.

(Вы можете менять эти шаги на любые другие, автоматизируя рутинные задачи в вашем проекте!)
